### Kurulum

1. Repoyu klonlayın:
   ```bash
   git clone https://github.com/nolyrica/discord-server-copy.git
   cd discord-server-copy
   ```

2. Bağımlılıkları yükleyin:
   ```bash
   npm install
   ```

3. Ortam değişkenlerini yapılandırın (`.env.local` oluşturun):
   ```env
   NEXT_PUBLIC_API_PASSWORD=sizin_güvenli_şifreniz
   ```

4. Uygulamayı başlatın:
   ```bash
   npm run dev
   ```

# 🌌 Matessa - Advanced Discord Server Cloner

**Matessa** is a professional cloning engine with a modern brutalist interface, designed to replicate Discord servers down to the last pixel. It combines security, speed, and ease of use to take server management to the next level.

---

## 🌟 Key Features

- **🎯 Flawless Replication**: Seamlessly copies Channels, Categories, Roles, Permissions, and Emojis.
- **⚡ Smart Delay & Fast Mode**:
  - **🛡️ Safe Mode (1000ms)**: Balanced mode prioritizing account safety.
  - **🚀 Fast Mode (500ms)**: Optimized high-speed cloning for speed enthusiasts.
- **🔒 Advanced Security Layer**:
  - **✅ Pre-Flight Check**: Validates Token and Administrator permissions before starting.
  - **⏭️ Smart Skip**: Automatically skips problematic steps (after 3 consecutive errors) and continues the process.
- **📱 Ultra-Responsive Design**: A sleek, eye-pleasing brutalist UI that works perfectly on both desktop and mobile devices.
- **🌍 11 Language Support**: Global accessibility with TR, EN, ES, FR, DE, PT, IT, RU, JA, AR, ID support.
- **📡 Live Log System**: Terminal-style log screen to monitor every step in real-time.

---

## 🚀 Quick Start

### Prerequisites
- [Node.js 18+](https://nodejs.org/)
- Discord User Token (Compliance with Self-Bot policies is required)
- Join our [Discord Server](https://discord.gg/huzunlerimsin) for support!

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/nolyrica/discord-server-copy.git
   cd discord-server-copy
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables (create `.env.local`):
   ```env
   NEXT_PUBLIC_API_PASSWORD=your_secure_password
   ```

4. Start the application:
   ```bash
   npm run dev
   ```
